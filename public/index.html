Getting started

The essentials for choosing, installing, and using your first Skill.

What is an Agent Skill?

A Skill is a reusable set of instructions and resources that helps an AI agent complete a specific kind of work.

Who makes the Skills on skillskr?

Our own team. Every Skill is designed, written and tested in-house, from the example on its page to the templates and scripts inside the package, and we keep updating it after release.

How do I get started?

Sign in, browse the catalog and choose a Skill, then use its install prompt or download its ZIP. Free Skills only need a free account. Your agent follows the included instructions after installation.

Will this work with my Agent?

The catalog works with agents that can read and install Agent Skills. Start with the supported examples on this page, then follow your agent's normal Skill installation flow.

Do I need an API key?

Not to connect skillskr: the CLI signs you in through your browser and keeps a revocable credential in your system keychain. Some Skills that generate images or video call outside AI models, such as FAL, with your own API key, and that provider bills you per use. Each Skill page lists what it needs before you install it.

What kinds of work can Skills help with?

Skills cover focused work across Slides, Web, Images, and Video. Each Skill page explains the result it helps your agent create before you install it.

How do I get Skill updates?

Install it again when a new version is out: rerun the install command with --force, or download the latest ZIP from the Skill page. Each Skill page shows its current version, and paid access includes every update.
